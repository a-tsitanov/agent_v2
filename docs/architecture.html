kb-llamaindex

Многоязычный RAG-сервис на LlamaIndex с инкрементальным графом знаний. Принимает документы, нормализует сущности в Wikibase / Neo4j / Milvus, обслуживает hybrid- и agentic-поиск через FastAPI. Полностью async, Temporal-оркестрация, self-hosted observability.

Ingest pipeline · Temporal workflow

9 активностей. Тяжёлые LLM-шаги изолированы в queue kb-ingest-llm с concurrency=1 чтобы не положить GPU.
01 fetch_source Скачать файл из MinIO (s3-URI из Postgres-job). kb-ingest
02 parse_and_chunk Парсинг (PDF/MD/TXT) + семантический чанкинг. kb-ingest
03 index_vector BGE-M3 embeddings → запись в Milvus collection. kb-ingest-llm
04 inject_canonical Regex/heuristics: ИНН, телефоны, e-mail, IMEI, VIN — 24 типа. kb-ingest
05 extract_kg LLM-извлечение сущностей и отношений (Qwen3:8b). kb-ingest-llm
06 merge_and_resolve ER: дедупликация сущностей по графу + identifier-folding. kb-ingest-llm
07 build_property_graph Запись KG в Neo4j: :__Entity__, :Chunk, типизир. рёбра. kb-ingest
08 push_wikibase Owner-сущности → Items, идентификаторы → external-id, отношения → claims. kb-ingest
09 finalize Финальный статус в Postgres + cleanup staging-блобов. kb-ingest

Архитектурные слои приложения

Тонкий HTTP-edge → durable orchestrator → пять хранилищ + ML gateway. Падение любого хранилища не блокирует ingest целиком — best-effort graceful degradation.

API layer · публичный edge

FastAPI / uvicorn
POST /api/v1/ingestupload + enqueue Temporal workflow
POST /api/v1/searchhybrid retrieval (vector + graph)
POST /api/v1/agentReAct agentic search
POST /api/v1/selfragSelf-RAG reflective synthesis
GET /healthzdeps health-probe

Orchestration layer · durable workflows

Temporal · 2 task queues
DocumentIngestWorkflow9 активностей, retry-policies, heartbeats
kb-ingest (concurrency=4)лёгкие шаги: I/O, парсинг, запись
kb-ingest-llm (concurrency=1)LLM-heavy: extract_kg, merge_and_resolve
best-effort fallbackсбой push_wikibase → vector_only, workflow not failed
