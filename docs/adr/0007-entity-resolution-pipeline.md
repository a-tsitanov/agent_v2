# ADR-0007: Entity Resolution = генерация кандидатов + LLM-судья + кэш вердиктов + union-find

- Статус: Принято
- Дата: 2026-06-07

## Контекст

Орфографический dedup (нормализация по имени) оставляет семантически
эквивалентные дубликаты: межъязыковые (`BCC` ≡ `Базальноклеточный Рак`),
аббревиатуры, варианты порядка слов/морфологии, инициализмы
(`Иванов И.И.` ≡ `Иван Иванов`) и междокументные варианты. Наивно судить LLM-ом
каждую пару — это O(N²) вызовов и недетерминированно; наивное автослияние по
сходству эмбеддингов чрезмерно сливает различные сущности, со-встречающиеся в
похожих контекстах.

## Решение

Многоэтапный конвейер **с блокировкой по эмбеддингам и подтверждением LLM**:
1. исключить метки детерминированных идентификаторов (ADR-0005);
2. эмбеддить сущности (батчами); детерминированный pre-pass (инициализм +
   deep-normal);
3. **векторизованная генерация кандидатов** — top-K косинусных соседей с той же
   меткой выше порога, с обходом/защитой по перекрытию токенов имени против
   загрязнения контекстом описания;
4. **автослияние** только когда косинус ≥ HIGH И тот же скрипт (межскриптовые
   всегда идут к судье);
5. **LLM-судья** для пограничных пар (батчами, JSON SAME/DIFFERENT/UNSURE), по
   умолчанию DIFFERENT при любом сбое/таймауте;
6. **персистентный кэш вердиктов** (`:ERVerdict`, ключ нечувствителен к порядку)
   пропускает повторное судейство повторяющихся пар (опционально, fail-safe);
7. **union-find** → кластеры, с верификацией кластера (вызов консолидации) для
   отмены транзитивного чрезмерного слияния и зажимом гипер-хабов, который
   помечает огромные кластеры `er_review_needed` вместо слияния.

## Последствия

- Консервативно по умолчанию: каждый сбой LLM маршрутизируется в DIFFERENT, так
  что ER никогда не засоряет граф ложноположительными слияниями; межскриптовые
  всегда верифицируются.
- Кэш вердиктов сокращает повторную стоимость LLM на повторных
  ingest-ах/хаб-тяжёлых документах; векторизованные косинусы убирают обрыв
  чисто-питоновской генерации кандидатов.
- Обязывает нас к эмбеддингам + LLM-судье в полосе merge и к подбору множества
  порогов (`ERConfig`); инкрементальный междокументный ER читает сохранённые
  каноники.

## Рассмотренные альтернативы

- **Чистое автослияние по эмбеддингам** — чрезмерно сливает различные
  со-встречающиеся сущности.
- **Судить каждую пару в каждом прогоне** — O(N²) стоимости LLM и
  недетерминизм; pre-pass + блокировка + кэш резко это сокращают.
